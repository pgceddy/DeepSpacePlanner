Processing Notes

A working reference for taking Seestar S50 data from stack to finish, organized by what kind of target you pointed at. Siril-first, with PixInsight notes where it helps.

Each stacking step below shows three ways to apply it: editing Seestar_preprocessing.ssf directly (best if you want it to happen automatically every run), the Stacking tab in Siril's GUI (Sequence tab → Search Sequences → load the sequence → Stacking tab — good for one-off tweaks), or typing the command straight into Siril's console.

GALAXY

Small, faint galaxy

size < 5′ · mag > 10 — e.g. NGC 6340, most field galaxies near a brighter target

  1. Stack with Winsorized or Linear Fit Clipping rejection. Rejects outliers and satellite trails without discarding faint real signal. edit the stack line in Seestar_preprocessing.ssf: change to "stack r_pp_light rej w 3 3 -norm=addscale -output_norm -rgb_equal -out=result" Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Rejection: Winsorized Sigma Clipping, sigma 3 / 3 → Start Stacking stack r_pp_light rej w 3 3 -norm=addscale -output_norm
  2. Run Background Extraction before any stretch. Sample points only in clean sky around the galaxy — never on or near the core. Image Processing → Background Extraction → RBF, place sample points manually around (not on) the galaxy subsky -rbf -samples=20
  3. Photometric Color Calibration (PCC). Works well as long as the field has a reasonable star count. Image Processing → Color Calibration → Photometric Color Calibration pcc
  4. Stretch with Generalized Hyperbolic Stretch (GHS), not a single Asinh pass. Gives control to pull up the faint core without blowing out field stars. Image Processing → Generalized Hyperbolic Stretch — start with a low stretch factor (SP near shadow clip), iterate in small passes
  5. Denoise before sharpening. At this size and brightness you're fighting noise more than resolving detail. Image Processing → Noise Reduction (or export to PixInsight for NoiseXTerminator) denoise -nocosmetic
  6. Crop in tight. The galaxy occupies a small fraction of the frame — cropping first makes every later stretch/curve decision easier. Drag a selection box over the galaxy, then Image → Crop (or press the crop icon) crop x y width height
  7. Optional: star reduction. Helps a small faint galaxy visually hold its own against the field instead of getting lost among stars. Generate a star mask (Star Recomposition tool or PixInsight StarNet), reduce star layer size/intensity, recombine

GALAXY

Medium galaxy

size 5′–15′, moderate surface brightness — e.g. M94

  1. Standard calibrate → register → stack with Winsorized rejection. edit Seestar_preprocessing.ssf stack line to "stack r_pp_light rej w 3 3 -norm=addscale -output_norm -rgb_equal -out=result", then run the full script Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized Sigma Clipping, sigma 3 / 3 calibrate light -dark=dark_stacked -flat=flat_stacked -cfa -debayer register pp_light stack r_pp_light rej w 3 3 -norm=addscale -output_norm
  2. Background Extraction, sampling well outside the galaxy's outer disk. Image Processing → Background Extraction → RBF or Polynomial degree 2–4 subsky -rbf -samples=20
  3. PCC for color, then a moderate GHS or Asinh stretch — you have more dynamic range to work with than a faint target, so you can afford a gentler curve. pcc then Image Processing → Generalized Hyperbolic Stretch, moderate strength
  4. Sharpen the core selectively (star mask or luminance mask) once structure is visible, rather than sharpening the whole frame. Extract luminance (if OSC: Image → Extract Channels), apply Wavelet/Unsharp sharpening to luminance only, recombine
  5. Light denoise on the outer disk/halo, where signal thins out fastest. Image Processing → Noise Reduction, lower strength than a faint-target pass, masked to the outer disk if needed

GALAXY

Large galaxy or galaxy group

size > 15′, or a cluster of galaxies in one field — e.g. Markarian's Chain, Coma Cluster field

  1. Stack with generous frame count — large fields benefit from drizzle integration if you have the subs for it. edit Seestar_preprocessing.ssf stack line, add drizzle options: "stack r_pp_light rej w 3 3 -drizzle -scale=2.0 -pixfrac=0.7 -norm=addscale -output_norm -rgb_equal -out=result" Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized, sigma 3/3, tick Drizzle (scale 2.0, pixel fraction 0.7) stack r_pp_light rej w 3 3 -drizzle -scale=2.0 -pixfrac=0.7 -norm=addscale -output_norm
  2. Background Extraction with more sample points, spread around the full frame margin since gradients are more visible across a wider field. Image Processing → Background Extraction → RBF, manually add 30+ sample points around the frame perimeter subsky -rbf -samples=30
  3. SPCC (Spectrophotometric Color Calibration) in PixInsight if available — more accurate across multiple galaxies of different types than single-target PCC. PixInsight → Process → Color Calibration → SpectrophotometricColorCalibration
  4. Stretch in stages: a first pass for the brightest cores, a second targeted pass for fainter group members, blended back together. Duplicate the image, stretch each copy differently (core-protected vs. group-boosted), blend with a luminance mask
  5. Annotate before you crop. Worth running an Aladin/SIMBAD overlay pass to catch fainter cluster members or background quasars before you commit to a final frame. Load the stacked frame in Aladin Desktop, overlay SIMBAD catalog, cross-check faint sources before finalizing the crop

NEBULA

Small nebula

size < 15′ — compact emission or reflection nebulae

  1. Stack with rejection tuned to preserve faint extended signal — avoid overly aggressive clipping. edit Seestar_preprocessing.ssf: "stack r_pp_light rej w 2.5 3 -norm=addscale -output_norm -rgb_equal -out=result" Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized, sigma low 2.5 / high 3 stack r_pp_light rej w 2.5 3 -norm=addscale -output_norm
  2. Background Extraction, being careful with sample placement since nebulosity can extend further than it first appears. Image Processing → Background Extraction → RBF, zoom out first to confirm where nebulosity actually ends before placing samples
  3. Stretch with masking: protect the brightest core while pulling up faint outer wisps separately. Create a luminance/range mask isolating the bright core, invert it to protect that region, stretch the rest more aggressively
  4. Star reduction and/or masking for nebula enhancement — the technique you used on Ghost Nebula (VdB 141) applies directly here. Adobe Camera Raw: star-mask via Select Subject/manual mask, reduce clarity/size on stars, boost local contrast on nebula only
  5. Watch for mosaic seams if you've combined multiple Seestar sessions or panels. Image Processing → Background Extraction, sample along seam lines specifically; feather the blend if seams persist

NEBULA

Large diffuse nebula

size > 15′, low surface brightness — e.g. Sh2-216/232/235-type targets

  1. Longer integration matters more here than almost any other target type. Diffuse, low-surface-brightness nebulosity needs signal, not clever processing, to appear at all. Plan for 90+ minutes of stacked Seestar integration where possible before moving to processing
  2. Background Extraction is critical — large diffuse nebulae are easy to confuse with genuine gradients. Sample generously and check the extracted background model before subtracting. Image Processing → Background Extraction → RBF, tick "show background" to inspect the model before applying subsky -rbf -samples=30
  3. Stretch gently and in multiple passes rather than one aggressive curve — you're trying to reveal faint extended structure without crushing it into flat gray. Image Processing → Generalized Hyperbolic Stretch, apply in 2–3 low-strength passes rather than one strong pass
  4. Consider narrowband-style contrast boosts even from broadband OSC data (e.g. selective saturation on H-alpha-rich regions) if the Seestar's filter and target support it. Color Calibration → adjust saturation curve, boost red/magenta channel selectively via Selective Color or Hue/Saturation tool
  5. Denoise before the final stretch pass, not after — noise gets amplified fastest in the shadow/midtone push these targets need. denoise -nocosmetic apply before the last GHS pass, not after

NEBULA

Planetary nebula

small, high surface brightness, sharp-edged

  1. Stack tight — these targets are usually bright enough that shorter integrations still work; the challenge is resolution, not signal. edit Seestar_preprocessing.ssf: "stack r_pp_light rej w 3 3 -norm=addscale -output_norm -rgb_equal -out=result" Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized, sigma 3 / 3 stack r_pp_light rej w 3 3 -norm=addscale -output_norm
  2. Minimal background extraction needed — the field around a planetary nebula is usually clean. Image Processing → Background Extraction → Polynomial degree 1, light touch only
  3. Aggressive but careful stretch on the shell, protecting the central star/core from clipping. Mask the central star/core (star mask, inverted), stretch the shell aggressively with GHS while the core stays protected
  4. Sharpen the shell edge specifically — this is one of the few target types where real sharpening (not just noise reduction) pays off at S50 resolution. Wavelet sharpening or Unsharp Mask, small radius, applied to a mask isolating the shell edge
  5. Crop tight and consider a modest zoom/scale-up in post since the object itself is small in-frame. crop x y width height then Image → Resample, 150–200% with a smooth interpolation (Lanczos)

CLUSTER

Open cluster

loose group of stars, wide range of brightness

  1. Shorter integration is often fine. Stars are point sources with good SNR relative to diffuse targets — don't over-integrate at the expense of a session on something fainter.
  2. Background Extraction is usually light-touch — clusters rarely have strong gradients unless embedded in nebulosity. Image Processing → Background Extraction → Polynomial degree 1–2
  3. PCC for accurate star colors — this is where color calibration actually shows, since the eye reads star color directly. pcc
  4. Avoid heavy star reduction — the stars are the subject, not competition for it. Skip star reduction tools entirely, or use at very low strength if star-crowding is an issue
  5. Watch bright-star halos/blooming and manage with a gentle highlight rolloff rather than clipping. Curves tool: pull the highlight rolloff down slightly rather than clipping the top of the histogram

CLUSTER

Globular cluster

dense, compact stellar core

  1. Protect the core from saturation during stack/stretch. Dense cores clip easily; a mask that limits the stretch there while pulling up the fainter outer stars separately makes a real difference. Create a radial mask centered on the core, invert to protect it during global stretch operations
  2. Background Extraction as usual, sampling outside the cluster's halo. subsky -rbf -samples=20
  3. Deconvolution (PixInsight) can help resolve core stars if seeing/tracking allowed sharp subs — otherwise skip it, it will just amplify noise. PixInsight → Process → Deconvolution, low iteration count, check for ringing artifacts before committing
  4. Stretch in two zones: a restrained curve for the core, a stronger one for the resolved outer stars, blended with a radial or luminance mask. Duplicate image, apply GHS at two strengths, blend via radial gradient mask centered on the core

GENERAL

General / unsure what you're looking at

fallback workflow — works reasonably for most targets

  1. Calibrate, register, stack with Winsorized rejection. edit Seestar_preprocessing.ssf stack line to "stack r_pp_light rej w 3 3 -norm=addscale -output_norm -rgb_equal -out=result", then run the script end to end Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized Sigma Clipping, sigma 3 / 3 → Start Stacking calibrate light -dark=dark_stacked -flat=flat_stacked -cfa -debayer register pp_light stack r_pp_light rej w 3 3 -norm=addscale -output_norm
  2. Background Extraction before any stretch. subsky -rbf -samples=20
  3. PCC for color calibration. pcc
  4. GHS stretch, checking histogram carefully rather than trusting autostretch defaults. Image Processing → Generalized Hyperbolic Stretch, watch the histogram panel as you adjust rather than relying on the auto preview
  5. Denoise, then decide whether the target needs sharpening, star reduction, or neither — that call depends on what showed up once background and stretch are done. denoise -nocosmetic
