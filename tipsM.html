Processing Notes

A working reference for taking Seestar S50 data from stack to finish, organized by what kind of target you pointed at. Siril-first, with PixInsight notes where it helps.

Each stacking step below shows three ways to apply it: editing Seestar_preprocessing.ssf directly (best if you want it to happen automatically every run), the Stacking tab in Siril's GUI (Sequence tab → Search Sequences → load the sequence → Stacking tab — good for one-off tweaks), or typing the command straight into Siril's console.

GALAXY

Small, faint galaxy

size < 5′ · mag > 10 — e.g. NGC 6340, most field galaxies near a brighter target

  1. Stack with Winsorized or Linear Fit Clipping rejection. Rejects outliers and satellite trails without discarding faint real signal. edit the stack line in Seestar_preprocessing.ssf: change to "stack r_pp_light rej w 3 3 -norm=addscale -output_norm -rgb_equal -out=result" Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Rejection: Winsorized Sigma Clipping, sigma 3 / 3 → Start Stacking stack r_pp_light rej w 3 3 -norm=addscale -output_norm
  2. Run Background Extraction before any stretch. Sample points only in clean sky around the galaxy — never on or near the core. Image Processing → Background Extraction → RBF, place sample points manually around (not on) the galaxy subsky -rbf -samples=20
  3. Spectrophotometric Color Calibration (SPCC). More accurate than PCC and makes it obsolete — worth using by default now that it's built into Siril (1.4+). Needs the image plate-solved first, same as PCC did. Ctrl+Shift+C, or Image Processing → Color Calibration → Spectrophotometric Color Calibration spcc
  4. Stretch with Generalized Hyperbolic Stretch (GHS), not a single Asinh pass. Gives control to pull up the faint core without blowing out field stars. Image Processing → Generalized Hyperbolic Stretch — start with a low stretch factor (SP near shadow clip), iterate in small passes
  5. Denoise before sharpening. At this size and brightness you're fighting noise more than resolving detail. Image Processing → Noise Reduction (or export to PixInsight for NoiseXTerminator) denoise -nocosmetic
  6. Crop in tight. The galaxy occupies a small fraction of the frame — cropping first makes every later stretch/curve decision easier. Drag a selection box over the galaxy, then Image → Crop (or press the crop icon) crop x y width height
  7. Optional: star reduction. Helps a small faint galaxy visually hold its own against the field instead of getting lost among stars. Generate a star mask (Star Recomposition tool or PixInsight StarNet), reduce star layer size/intensity, recombine

GALAXY

Medium galaxy

size 5′–15′, moderate surface brightness — e.g. M94

  1. Standard calibrate → register → stack with Winsorized rejection. edit Seestar_preprocessing.ssf stack line to "stack r_pp_light rej w 3 3 -norm=addscale -output_norm -rgb_equal -out=result", then run the full script Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized Sigma Clipping, sigma 3 / 3 calibrate light -dark=dark_stacked -flat=flat_stacked -cfa -debayer register pp_light stack r_pp_light rej w 3 3 -norm=addscale -output_norm
  2. Background Extraction, sampling well outside the galaxy's outer disk. Image Processing → Background Extraction → RBF or Polynomial degree 2–4 subsky -rbf -samples=20
  3. SPCC for color — always before stretching, on linear data. spcc
  4. Stretch with GHS in small passes, protecting the core. For a compact bright nucleus with a much fainter extended disk (e.g. a lenticular like NGC 5866), a single aggressive stretch will clip the core before the disk is even visible. Low stretch factor + moderate black point brings up the faint disk without blowing out the nucleus; using the local stretch/symmetry point keeps the pull targeted at shadows/midtones and leaves highlights alone. Do 2–3 gentle passes rather than one big one, checking the histogram between each. Image Processing → Generalized Hyperbolic Stretch — start with a low D (stretch factor), moderate SP (black point/symmetry point), iterate in small passes
  5. Optional: gentle S-curve once GHS has the overall range roughly right, for extra contrast without hammering the core further. Image Processing → Curves, subtle S-curve
  6. Sharpen the core selectively (star mask or luminance mask) once structure is visible, rather than sharpening the whole frame. Two ways to do this — pick whichever you're comfortable with: Sharpening only affects brightness/structure, not color, so you avoid shifting color balance or fringing edges (like a dust lane) the way sharpening RGB directly can.
    Easier — masked sharpen, no channel split: apply Wavelet Transform directly to the color image, using a luminance-based or star mask to confine the effect to the core. No extraction or recombination step needed. Image Processing → Wavelet Transform — boost detail layers 2–3, ~1.2–1.5×, with a mask limiting the effect to the core
    More control — Lab extraction: pull out just the luminance, sharpen it, then recombine. 1) Image → Extract Channels → CIE L*a*b* (produces L, a, b files) 2) Image Processing → Wavelet Transform on the L file only — boost detail layers 2–3, ~1.2–1.5× 3) Image Processing → RGB Composition — load a into one slot, b into another, the sharpened L into the Luminance slot, tick "Use Luminance", then composite RGB Composition is the correct recombine tool — not Merge CFA, which is only for combining raw Bayer-filter subframes.
  7. If a dust lane looks harsh or banded after stretching, back off the GHS black point rather than reducing the sharpening pass — a crushed black point is the usual cause, not over-sharpening.
  8. Light denoise on the outer disk/halo, where signal thins out fastest. Image Processing → Noise Reduction, lower strength than a faint-target pass, masked to the outer disk if needed

GALAXY

Large galaxy or galaxy group

size > 15′, or a cluster of galaxies in one field — e.g. Markarian's Chain, Coma Cluster field, IC 342

  1. Stack with generous frame count — large fields benefit from drizzle integration if you have the subs for it. edit Seestar_preprocessing.ssf stack line, add drizzle options: "stack r_pp_light rej w 3 3 -drizzle -scale=2.0 -pixfrac=0.7 -norm=addscale -output_norm -rgb_equal -out=result" Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized, sigma 3/3, tick Drizzle (scale 2.0, pixel fraction 0.7) stack r_pp_light rej w 3 3 -drizzle -scale=2.0 -pixfrac=0.7 -norm=addscale -output_norm
  2. Background Extraction with more sample points, spread around the full frame margin since gradients are more visible across a wider field. Image Processing → Background Extraction → RBF, manually add 30+ sample points around the frame perimeter subsky -rbf -samples=30
  3. SPCC (Spectrophotometric Color Calibration) — more accurate across multiple galaxies of different types than PCC ever was, and it's built into Siril directly (1.4+), no need to round-trip through PixInsight anymore. Ctrl+Shift+C, or Image Processing → Color Calibration → Spectrophotometric Color Calibration spcc
  4. Stretch in stages: a first pass for the brightest cores, a second targeted pass for fainter group members, blended back together. Duplicate the image, stretch each copy differently (core-protected vs. group-boosted), blend with a luminance mask
  5. Annotate before you crop. Worth running an Aladin/SIMBAD overlay pass to catch fainter cluster members or background quasars before you commit to a final frame. Load the stacked frame in Aladin Desktop, overlay SIMBAD catalog, cross-check faint sources before finalizing the crop

Faint, large, low-surface-brightness case (e.g. IC 342, "The Hidden Galaxy") — same steps above, plus:

  1. Budget more integration than the size suggests. A 20′+ galaxy sounds bright given its Messier-catalog-adjacent size, but low surface brightness plus foreground Milky Way dust extinction (IC 342 sits near the galactic equator) means it behaves more like a faint target. Plan 1–2 hrs minimum; combining subs from separate sessions/nights is fine as long as each is background-extracted and SPCC'd individually before the final stack.
  2. Expect a warm/reddish color cast from foreground dust and don't try to fully correct it out — SPCC handles star colors correctly, but the galaxy's own reddening from Milky Way extinction is real, not a calibration error.
  3. If the outer disk is noisy after stack + stretch, denoise the background/halo only, not the whole frame. Aggressive whole-image noise reduction (including third-party tools like Topaz) will smear spiral arm and dust lane detail right along with the noise. See Background-only denoise for the masking technique.

NEBULA

Small nebula

size < 15′ — compact emission or reflection nebulae

  1. Stack with rejection tuned to preserve faint extended signal — avoid overly aggressive clipping. edit Seestar_preprocessing.ssf: "stack r_pp_light rej w 2.5 3 -norm=addscale -output_norm -rgb_equal -out=result" Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized, sigma low 2.5 / high 3 stack r_pp_light rej w 2.5 3 -norm=addscale -output_norm
  2. Background Extraction, being careful with sample placement since nebulosity can extend further than it first appears. Image Processing → Background Extraction → RBF, zoom out first to confirm where nebulosity actually ends before placing samples
  3. SPCC for color calibration — calibrates off field star photometry, so it still applies even though the nebula itself is the subject. Pick a background reference patch that's genuinely dark sky, not faint nebula glow. Ctrl+Shift+C, or Image Processing → Color Calibration → Spectrophotometric Color Calibration spcc
  4. Stretch with masking: protect the brightest core while pulling up faint outer wisps separately. Create a luminance/range mask isolating the bright core, invert it to protect that region, stretch the rest more aggressively
  5. Star reduction and/or masking for nebula enhancement — the technique you used on Ghost Nebula (VdB 141) applies directly here. Adobe Camera Raw: star-mask via Select Subject/manual mask, reduce clarity/size on stars, boost local contrast on nebula only
  6. Watch for mosaic seams if you've combined multiple Seestar sessions or panels. Image Processing → Background Extraction, sample along seam lines specifically; feather the blend if seams persist

NEBULA

Large diffuse nebula

size > 15′, low surface brightness — e.g. Sh2-216/232/235-type targets

  1. Longer integration matters more here than almost any other target type. Diffuse, low-surface-brightness nebulosity needs signal, not clever processing, to appear at all. Plan for 90+ minutes of stacked Seestar integration where possible before moving to processing
  2. Background Extraction is critical — large diffuse nebulae are easy to confuse with genuine gradients. Sample generously and check the extracted background model before subtracting. Image Processing → Background Extraction → RBF, tick "show background" to inspect the model before applying subsky -rbf -samples=30
  3. SPCC for color calibration — run this before any saturation/narrowband-style boosts below, so those boosts are pushing from an already-correct color baseline rather than compensating for an uncalibrated one. Ctrl+Shift+C, or Image Processing → Color Calibration → Spectrophotometric Color Calibration spcc
  4. Stretch gently and in multiple passes rather than one aggressive curve — you're trying to reveal faint extended structure without crushing it into flat gray. Image Processing → Generalized Hyperbolic Stretch, apply in 2–3 low-strength passes rather than one strong pass
  5. Consider narrowband-style contrast boosts even from broadband OSC data (e.g. selective saturation on H-alpha-rich regions) if the Seestar's filter and target support it. Color Calibration → adjust saturation curve, boost red/magenta channel selectively via Selective Color or Hue/Saturation tool
  6. Denoise before the final stretch pass, not after — noise gets amplified fastest in the shadow/midtone push these targets need. denoise -nocosmetic apply before the last GHS pass, not after

NEBULA

Planetary nebula

small, high surface brightness, sharp-edged

  1. Stack tight — these targets are usually bright enough that shorter integrations still work; the challenge is resolution, not signal. edit Seestar_preprocessing.ssf: "stack r_pp_light rej w 3 3 -norm=addscale -output_norm -rgb_equal -out=result" Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized, sigma 3 / 3 stack r_pp_light rej w 3 3 -norm=addscale -output_norm
  2. Minimal background extraction needed — the field around a planetary nebula is usually clean. Image Processing → Background Extraction → Polynomial degree 1, light touch only
  3. SPCC for color calibration — worth doing even on a small, bright target, since it's calibrating the field stars rather than the shell itself. Ctrl+Shift+C, or Image Processing → Color Calibration → Spectrophotometric Color Calibration spcc
  4. Aggressive but careful stretch on the shell, protecting the central star/core from clipping. Mask the central star/core (star mask, inverted), stretch the shell aggressively with GHS while the core stays protected
  5. Sharpen the shell edge specifically — this is one of the few target types where real sharpening (not just noise reduction) pays off at S50 resolution. Wavelet sharpening or Unsharp Mask, small radius, applied to a mask isolating the shell edge
  6. Crop tight and consider a modest zoom/scale-up in post since the object itself is small in-frame. crop x y width height then Image → Resample, 150–200% with a smooth interpolation (Lanczos)

CLUSTER

Open cluster

loose group of stars, wide range of brightness

  1. Shorter integration is often fine. Stars are point sources with good SNR relative to diffuse targets — don't over-integrate at the expense of a session on something fainter.
  2. Background Extraction is usually light-touch — clusters rarely have strong gradients unless embedded in nebulosity. Image Processing → Background Extraction → Polynomial degree 1–2
  3. SPCC for accurate star colors — this is where color calibration actually shows, since the eye reads star color directly. spcc
  4. Avoid heavy star reduction — the stars are the subject, not competition for it. Skip star reduction tools entirely, or use at very low strength if star-crowding is an issue
  5. Watch bright-star halos/blooming and manage with a gentle highlight rolloff rather than clipping. Curves tool: pull the highlight rolloff down slightly rather than clipping the top of the histogram

CLUSTER

Globular cluster

dense, compact stellar core

  1. Protect the core from saturation during stack/stretch. Dense cores clip easily; a mask that limits the stretch there while pulling up the fainter outer stars separately makes a real difference. Create a radial mask centered on the core, invert to protect it during global stretch operations
  2. Background Extraction as usual, sampling outside the cluster's halo. subsky -rbf -samples=20
  3. Deconvolution (PixInsight) can help resolve core stars if seeing/tracking allowed sharp subs — otherwise skip it, it will just amplify noise. PixInsight → Process → Deconvolution, low iteration count, check for ringing artifacts before committing
  4. Stretch in two zones: a restrained curve for the core, a stronger one for the resolved outer stars, blended with a radial or luminance mask. Duplicate image, apply GHS at two strengths, blend via radial gradient mask centered on the core

GENERAL

General / unsure what you're looking at

fallback workflow — works reasonably for most targets

  1. Calibrate, register, stack with Winsorized rejection. edit Seestar_preprocessing.ssf stack line to "stack r_pp_light rej w 3 3 -norm=addscale -output_norm -rgb_equal -out=result", then run the script end to end Sequence tab → Search Sequences → load r_pp_light → Stacking tab → Winsorized Sigma Clipping, sigma 3 / 3 → Start Stacking calibrate light -dark=dark_stacked -flat=flat_stacked -cfa -debayer register pp_light stack r_pp_light rej w 3 3 -norm=addscale -output_norm
  2. Background Extraction before any stretch. subsky -rbf -samples=20
  3. SPCC for color calibration. spcc
  4. GHS stretch, checking histogram carefully rather than trusting autostretch defaults. Image Processing → Generalized Hyperbolic Stretch, watch the histogram panel as you adjust rather than relying on the auto preview
  5. Denoise, then decide whether the target needs sharpening, star reduction, or neither — that call depends on what showed up once background and stretch are done. denoise -nocosmetic

TECHNIQUE

Dust lanes & fine internal structure

edge-on or inclined galaxies with dark absorption features, or any target with fine tonal detail worth preserving — e.g. NGC 5866, NGC 5907

  1. Sharpen the luminance only, not the whole RGB stack. Sharpening a color image directly can fringe or shift color right at the dust lane edge. Splitting to Lab and sharpening L keeps structure and color independent. 1) Image → Extract Channels → CIE L*a*b* (produces L, a, b files) 2) Image Processing → Wavelet Transform on the L file only — boost detail layers 2–3, ~1.2–1.5× 3) Image Processing → RGB Composition — load a into one slot, b into another, the sharpened L into the Luminance slot, tick "Use Luminance", then composite
  2. If the dust lane looks harsh or banded after stretching, back off the GHS black point (SP) first — a crushed black point is the usual cause, not over-sharpening. Reducing the sharpen pass first just masks the real problem.
  3. Isolate the lane for a targeted local-contrast pass once the overall stretch is right, rather than pushing contrast globally. Select the dust lane's tonal range (Color Range on shadows, feathered), apply Local Contrast/Clarity within that selection only
  4. Finish with light hand dodge/burn along the lane — see Dimensional / 3D look for the technique.

TECHNIQUE

Accurate star colors

any target where star color is part of the payoff — open clusters, wide fields, galaxy fields with foreground stars

  1. Run SPCC before any saturation work or stretch. SPCC calibrates against field star photometry, which needs mostly-linear data — running it after a stretch skews the result. Ctrl+Shift+C, or Image Processing → Color Calibration → Spectrophotometric Color Calibration spcc
  2. Pick a genuinely dark-sky patch for the background reference when SPCC prompts for one — not faint nebula glow, which will bias the whole calibration.
  3. Protect star cores from clipping during stretch. A blown-out core loses its color information first — once it's pure white there's nothing left to read. Curves tool: pull the highlight rolloff down slightly rather than clipping the top of the histogram
  4. If colors look washed out after a strong stretch, boost saturation selectively on star tones (Hue/Saturation targeted range) rather than a global bump that also shifts nebula or galaxy color.

TECHNIQUE

Protecting a bright core while pulling up faint structure

compact bright nucleus with much fainter surrounding structure — lenticular galaxies, globular cluster cores, planetary nebula shells

  1. Build a mask isolating the bright region — a radial mask for clusters/planetary nebulae, a luminance or range mask for a galaxy nucleus. Create a radial or luminance/range mask centered on the bright feature
  2. Invert the mask to protect that region, then stretch the rest more aggressively. GHS in low-D, moderate-SP passes works better than one large pull. Image Processing → Generalized Hyperbolic Stretch, low stretch factor, iterate in 2–3 small passes with the mask active
  3. For two genuinely different brightness zones (e.g. a globular's core vs. its resolved outer stars), stretch two duplicate copies at different strengths and blend with the same mask rather than hunting for one curve that satisfies both. Duplicate image, apply GHS at two strengths, blend via the radial/luminance mask
  4. Check the histogram between each pass rather than trusting the autostretch preview — it's easy to over-stretch the protected side without noticing until you look at the numbers.

TECHNIQUE

De-emphasizing stars to favor the real subject

when stars compete visually with the actual subject — small faint galaxies, nebulae with dense foreground star fields

  1. Generate a star mask — PixInsight StarNet, or Adobe Camera Raw's Select Subject / manual mask, whichever's already in your pipeline for that session. Adobe Camera Raw: star-mask via Select Subject or manual mask PixInsight: StarNet star removal, keep the extracted star layer separately
  2. Reduce star size/intensity on the masked layer only, not the underlying nebula or galaxy signal.
  3. Recombine and check for halos around the largest stars — a too-aggressive reduction leaves a visible ring; back off if so.
  4. Skip this entirely for open clusters and anything where the stars themselves are the subject — reducing them there works against the target, not for it.

TECHNIQUE

Background-only denoise (masked)

noisy outer halo/background on a faint or long-integration target, done as a Photoshop finishing pass after Siril — e.g. IC 342's outer disk

  1. Duplicate the finished (pre-denoise) layer. Work on the duplicate so the sharp original is always there to fall back to.
  2. Select the galaxy/nebula itself with a loose lasso or oval — doesn't need to be precise. A rough selection is fine because the next step (feathering) does the real work of making the transition invisible.
  3. Feather the selection generously (30–50px) so there's no hard edge between treated and untreated regions. Select → Modify → Feather, 30–50px depending on image resolution
  4. Invert the selection so the background is selected and the subject is protected. Select → Inverse (Shift+Ctrl+I / Shift+Cmd+I)
  5. Run denoise only within that selection (Topaz DeNoise, Camera Raw, or similar) — favor chroma/color noise reduction over luminance, since luminance denoise is what smears real faint structure.
  6. Flatten and check the seam at 100% zoom. A visible ring or brightness step at the old selection boundary means the feather was too tight — undo and redo with a larger feather radius.
  7. If the galaxy's own edge still looks noisy right at the boundary, that's expected — the transition zone between subject and sky is inherently harder to clean without eating into real signal. Don't chase it further unless you're printing large or cropping in tight.

TECHNIQUE

Dimensional / "3D" look on a core or dust lane

adds a sense of depth to a bright core or absorption feature — a finishing pass, not a substitute for masking

  1. Do this last, after stretch, sharpen, and color work are done — it's a finishing touch, not a fix for an under-stretched image.
  2. Work on a duplicate luminance layer, low opacity (10–20%) brush, several light passes rather than one heavy one. Duplicate the luminance layer, set brush opacity 10–20%, build up the effect over multiple passes
  3. Burn along the inside edge of a dust lane or the shadow side of a core to suggest depth; dodge lightly on the opposite edge.
  4. Zoom out to check before flattening — it's easy to overdo this at 100% zoom and not notice until you back out and it looks artificial.

TECHNIQUE

Spotting a faint transient or supernova

checking a galaxy field against a reference epoch for a new point source — e.g. SN 2026kid in NGC 5907

  1. Stack the new session separately from archived data rather than combining, so the two epochs can be compared like-for-like.
  2. Register both stacks to the same reference frame so field stars line up pixel for pixel before comparison.
  3. Blink or difference the two frames (subtract one from the other). A genuine transient shows up as a bright point where nothing was before; noise and hot pixels won't line up consistently across epochs the way a real source does.
  4. Cross-check anything promising against a transient database (e.g. the Transient Name Server) before assuming it's new — plenty of "new" points turn out to be known variable stars or minor planets passing through the field.

TECHNIQUE

Mosaic seam management

combining multiple Seestar sessions or panels into one wider frame

  1. Register all panels to a common reference frame before stacking or blending.
  2. Run Background Extraction with sample points placed along the seam lines specifically, not just around the frame perimeter. Image Processing → Background Extraction, sample along seam lines specifically; feather the blend if seams persist
  3. Feather the blend across the seam if it's still visible after background matching.
  4. Check the seam again after the final stretch — gradients invisible in linear data can reappear once stretched.
